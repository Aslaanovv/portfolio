# Muhammad Aslaan — Portfolio

Personal portfolio platform for **Muhammad Aslaan**, Product Designer & Frontend Engineer — project case studies, service offerings, credentials, and a client contact pipeline in a single editorial, dark-themed experience.

**Live website:** [aslaansportfolio.vercel.app](https://aslaansportfolio.vercel.app)

## Overview & Key Capabilities

- **Case-study-driven presentation** — dedicated case-study pages for client and product work (Ehtwaa, Top Beauty Academy, YUCHIIE, La Camille, ADHERE Studio and more), with live-site links and outcome-focused narratives.
- **Editorial dark theme** — custom design tokens, Framer Motion animation system, and responsive layouts built around a restrained monochrome palette.
- **Client contact pipeline** — validated inquiry form with project-type, budget, and timeline qualification, delivered via EmailJS with an error-resilient fallback.
- **Credentials & services sections** — structured presentation of offerings and professional credentials.
- **Production deployment** — Vite SPA on Vercel with SPA rewrites and hardened HTTP security headers; optimized image pipeline for fast loads.

## Tech Stack

React 18 · TypeScript · Vite · Tailwind CSS · Radix UI · Wouter · Framer Motion · React Query · EmailJS · Vercel
